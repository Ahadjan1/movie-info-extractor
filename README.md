## 📊 Overview

This project demonstrates two different approaches to getting information out of an LLM:

1. **Plain Text Output**: uses `ChatPromptTemplate` with System + Human roles, returning a formatted text response.
2. **Structured Output**: uses Pydantic schemas (`with_structured_output`) to get clean, typed, machine-readable JSON.

A toggle lets the user switch between the two output modes in real time.

---

## 🧠 Features

- Accepts either a **movie name** or a **paragraph describing a movie**
- **Plain Text mode:** human-readable formatted response
- **Structured mode:** typed Pydantic schema output + raw JSON view
- Handles missing information gracefully (marks fields as "Not mentioned" instead of guessing)

## 📉 Known Limitations

| Limitation | Details |
|---|---|
| **Free API quota** | The shared free-tier key has a limited number of requests/tokens. Once used up, the app stops working. |
| **Rate limits** | Free-tier keys have low requests-per-minute limits, so rapid use can trigger errors. |
| **Model access** | Free keys may have usage caps on `mistral-small-latest`. |
| **Response time** | Free-tier requests can be slower or queued during busy periods. |
| **LLM knowledge** | When given only a movie name, results come from the model's training data. Details for very new or obscure movies may be missing or inaccurate. |
| **Not a movie database** | Output is generated by an LLM, not fetched from IMDb/TMDB, so always verify important details. |
| **No guaranteed uptime** | The demo depends on a third-party API and on Streamlit Community Cloud, which may put inactive apps to sleep. |
| **Data privacy** | Inputs are sent to Mistral's API. Do not enter sensitive or personal data. |

## 🚀 Running Locally

```bash
git clone https://github.com/Ahadjan1/movie-info-extractor.git
cd movie-info-extractor
uv venv
.venv\Scripts\activate        # Linux/Mac: source .venv/bin/activate
uv pip install -r requirements.txt
streamlit run movie_extractor_combined.py
```

You'll need a Mistral API key from the [Mistral Console](https://console.mistral.ai/). Add it to a `.env` file in the project root:

```env
MISTRAL_API_KEY=your_api_key_here
```

> 🔒 **Never commit your API key to GitHub.** Make sure `.env` is listed in `.gitignore`.

---

## ☁️ Deploy Your Own Copy on Streamlit Cloud

1. Fork this repository.
2. Go to [share.streamlit.io](https://share.streamlit.io) and create a new app from your fork.
3. Open **Settings → Secrets** and add:
   ```toml
   MISTRAL_API_KEY = "your_api_key_here"
   ```
4. Deploy. The app will now use your own quota.

## 🔄 Alternatives if the Quota Runs Out

- Upgrade to a paid Mistral plan for higher limits.
- Generate a new key after the free quota resets (if applicable).
- Switch to another provider with a free tier (e.g. Groq, Google Gemini, OpenRouter) by changing the LangChain model class in the code.
- Run an open-source model locally with [Ollama](https://ollama.com/) so no API key or quota is needed.
